## Introduction

:dl-prompter[pnpm prepare pathMap env app.config regenerate nuxt]

Practical sharp edges for this starter.

Run **`pnpm prepare`** after dependency or content-structure changes. DocLayer and Nuxt regenerate configs, path markers, and collection metadata under `.nuxt/`.

## Caveats

::dl-prompter
pnpm lint eslint vue-tsc gitignore app.vue
navigation depth collections headerNav DlRenderer shared
DL_META_ROBOTS noindex nofollow crawlers agents SEO
pnpm cleanup markdownlintignore content AGENTS skills favicons
::

- `.gitignore` includes `app/*.vue`. Nuxt ESLint honors `.gitignore`, so **shell Vue files in `app/` are skipped** by `pnpm lint:eslint`. Nested files under `app/**/*.(ts|vue)` are still checked. Drop that ignore entry, or run this, just once: :code[pnpm exec eslint app/app.vue --no-ignore]{style="white-space: nowrap;"}.
- `prepare` script writes gitignored **`content.config.ts`** and **`.markdownlint.json`**. Unless you mean to own them in Git, edit collections through DocLayer’s flow and re-run `prepare`.
- The `.example.env` sets `DL_META_ROBOTS` to `noindex, nofollow`, so **search engines and crawlers (including many AI agents) are asked not to index** the site. Change this when you deploy a public site that should appear in search or training crawlers. `robots.txt` follows this setting.
- `pnpm cleanup` removes `.nuxt` and `node_modules`; use when types or generated files look stale after upgrades. `pnpm cleanup:deep` removes caches additionally.
- `.markdownlintignore` excludes `content/_shared` as chunked Markdown may transgress rules unintentionally; remove when the Markdown is correct.
- Favicons are DocLayer's, change them by replacing in the `public/` folder.
- Agentic intro splits into multiple files to avoid overwhelming:
  - root `AGENTS.md` for general rules and instructions,
  - content-tied principles in `content/AGENTS.md`,
  - skills for even better content interaction in `.agents/skills`.
