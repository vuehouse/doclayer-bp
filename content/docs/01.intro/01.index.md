## Run the application

:dl-prompter[how to install and run the DocLayer boilerplate pnpm dev localhost 3000]
:dl-prompter[copy the env example file]

This project is a DocLayer Boilerplate: a Nuxt starter app with the :dl-link[$dl-docs]{label="`@vuehouse/dl` module" path="/getting-started"} already installed. You write Markdown, and DocLayer provides the theme, navigation, layout, and content components.

::dl-callout{title=false}

Use Node.js `20.20` or `22.10` (or a newer release on those major lines) and :dl-link[$pnpm] `10.34.5` or newer. Those ranges are set in `package.json`.

::

Install dependencies and start the dev server:

::dl-code{tabs="terminal.sh"}

```bash
pnpm i && pnpm dev
```

::

The site is served at `http://localhost:3000`.

::dl-callout{title=false type="note"}

Copy `.env.example` to `.env` when you set branding, SEO, search. The example file lists the variables this app reads.

::

Module install steps are widely described in the :dl-link[$dl-docs]{label="installation guide" path="/getting-started/installation"}.
